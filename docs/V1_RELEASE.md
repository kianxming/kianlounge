# 와노 전란기 v1.0.0 릴리스 기준

## 목표
v1은 "기능이 데이터 안에 존재한다"가 아니라 **한국어 사용자가 실제 브라우저에서 이해하고 한 번의 클릭으로 조작할 수 있는 전략 샌드박스**를 기준으로 한다.

## v1에서 완료한 사용자 경험
- 전체 주요 UI, 명령, 상태, 경고, 이벤트 피드 한국어화
- 루트 이벤트 위임 방식으로 입력 구조 변경: 렌더링 때 버튼 이벤트를 재부착하지 않음
- 입력/셀렉트 조작 중 자동 월드 렌더가 DOM을 교체하지 않음
- 와노 지도 벡터 아트, 7개 세력 엠블럼, 거점 타입 아이콘, 4단계 캐릭터 프레임
- CORE/대표 인물 초상화: 루피, 조로, 상디, 카이도, 빅 맘, 로, 키드, 야마토, 킹, 퀸
- 현재 구현된 악마의 열매/이름 있는 무기/패기 아이콘 세트
- 대표 전술 스프라이트: Large 카이도, Normal 로/조로, Small 쵸파 + fallback
- 지도/인물/특수 물품/전술 화면에 실제 에셋 연결

## 실제 브라우저 E2E 통과 기준
Playwright Chromium에서 PC와 태블릿 프로젝트를 각각 실행한다.
1. 첫 진입과 한국어 UI
2. 거점 한 번 클릭 → 해당 명령창 표시
3. 병력 모집 → 실제 병력 증가 + 피드백
4. 루피 군단 편성 → 에비스 이동
5. 나미 수송대 편성 → 별도 전략 유닛 생성
6. 인물 일람 → 조로 상세 → 패기 표시
7. 특수 물품 → 악마의 열매 표시
8. 외교 화면 진입
9. 저장/불러오기
10. 3배속 진행 → 적 조우 → 수동 전투 진입 → AUTO 복귀
11. 브라우저 console/page error 0
12. PC/태블릿 full-page screenshot 생성

## 유지되는 설계 비목표
Fog/Scouting, chase/pursuit, weapon durability, wounded troop recovery, random critical hit, forced canon events, Fruit extraction은 v1 범위에 추가하지 않는다.

## 그래픽 원칙
현재 v1 아트는 공식 애니/게임 스크린샷을 복제하지 않고, 팬게임 전략 UI에 맞춰 새로 그린 벡터 자산이다. 데이터와 에셋 ID는 분리되어 이후 고해상도 production asset으로 교체 가능하다.
